# UI Fix v0.32

## Исправлено

- Устранена причина неработающих переключателей типа портала: обработчик кнопки «Добавить портал» передавал `MouseEvent` в `openPortalWizard`, из-за чего мастер ошибочно считал, что редактируется существующий портал, и блокировал radio inputs.
- Выбор типа портала работает по клику на радиокнопку, подпись и всю карточку.
- Добавлены hover, focus и selected-состояния, а также управление с клавиатуры Enter/Space.
- Левый список порталов получил корректное ограничение высоты и независимую вертикальную прокрутку.
- Список обращений получил корректный flex-контейнер, ограничение высоты и независимую вертикальную прокрутку.
- Добавлена стилизация полос прокрутки для списка порталов, списка обращений и переписки.
- Обновлены cache-busting версии `style.css?v=032` и `script.js?v=032`.

## Проверено

- `node --check` для `script.js`.
- Баланс CSS-блоков и уникальность основных элементов формы.
- Компиляция всех Java main sources под Java 17 с библиотеками проекта.
- Два headless Chromium smoke-теста:
  - выбор ADMIN/CLIENT кликом на всю карточку и клавиатурой;
  - повторное открытие мастера без блокировки radio inputs;
  - переход со шага 1 на шаг 2 клиентского сценария;
  - прокрутка списка из 34 порталов;
  - прокрутка списка из 44 обращений.
